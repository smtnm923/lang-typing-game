# メモ
- Javaの授業で使ったJavaFXのひな形を使う
- main.fxmlをScene Buildrでタイトル画面、ゲーム画面、結果画面を切り替えられるように作成する。
	- StackPaneの中に3つVBoxの画面を重ねておく
	- labelや画面を切り替えられるようにボタンを置いて、fx:idを設定する
	- MainControllerを変更する
		- FXMLのフィールド作る
		- 画面を切り替えて表示するのにPaneを表示、非表示で切り替えするようにする。setVisible(true)で表示でsetVisible(true)で非表示になるようにする
		- initialize()のメソッドにボタンを押したときの処理を追加する。
- キーの入力周りを作成する。
	- 入力欄、入力している文字が分かるものを作成する。今後のことを考えてTextFieldではなくLabelを使用する。（TextFieldだとミスしたときにバックスペースを押す必要があったりEnterを押す必要があったり、キーボードの設定を変更しないと遊べない）
	- ハングルを英語キーボードで入力できるようにするため、HangulUtils.java を作成する
		- ハングルの1文字（例「한」）を、初声・中声・終声（ㅎ・ㅏ・ㄴ）に分解する
			- 順番が大切
			- 例：CHOSUNG[18] → 'ㅎ'　JUNGSUNG[0] → 'ㅏ'　JONGSUNG[4] → 'ㄴ'
		- 分解した各文字を、キーボードのアルファベット（g・k・s）に対応させる
		- 1打分のデータをまとめるために record で KeyStroke を作成する
		- displayJamo（表示する文字、ハングル）と keyChar（入力するキー、英語）を1セットにする
